
# Metin Tabanlı Macera Oyunu

Python ile geliştirilmiş, oyuncunun verdiği kararlara göre ilerleyen basit bir metin tabanlı macera oyunu.

## Özellikler
* Seçimlere bağlı farklı hikaye yolları ve sonlar
* Tamamen terminal (konsol) üzerinden oynanış

* ## Nasıl Oynanır?
1. Bilgisayarınızda Python kurulu olduğundan emin olun.
2. Dosyayı indirin ve terminalde oyunun olduğu klasöre gelin.
3. Aşağıdaki komutu yazarak oyunu başlatın:
   ```bash
   python oyun_dosyasinin_adi.py
